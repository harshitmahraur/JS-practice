# JavaScript Practice

My first JavaScript projects, built while learning .

## Faulty Calculator
Gives the correct answer only when a random number is greater than 0.1.

To run it, open `faulty-calculator/index.html` and Click on Go Live(on the bottom right corner).

## Business Name Generator
Creates business names from random word lists.

To run it, make sure Node.js is installed, then type this in the terminal:

node bussinesname\name.js
